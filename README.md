One funny line, 189 characters: the elevator pitch a city pigeon gives investors for its startup — "Investors, I'm raising a seed round — literally birdseed — for the app that turns every statue, bench, and dropped pretzel into recurring revenue. Pigeons never churn; we just coo and stay." The program in `main.ts` writes that single line to `entry.txt` in the output directory, after checking it fits the 1–200 character gate.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
